## Key Features

* **🎨 W3C DTCG Token Studio**: Color (Light/Dark dynamic modes), Typography, Spacing, Border Radius, Box Shadows.
* **🍏 Industry Presets**: Apple HIG, Tailwind CSS, Google Material Design 3, Ant Design.
* **⚡ Multi-Platform Code Exporter**: SwiftUI, UIKit, AppKit, Tailwind CSS, CSS Variables, Jetpack Compose, Flutter.
* **⚡ Direct Figma REST API Auto-Sync**: Push tokens directly into Figma file variables in seconds.
* **🤖 AI Agent System Context Exporter**: Generates structured `DESIGN_SYSTEM.md` context files.

## Installation

### Homebrew
```bash
brew tap mrKangHo/tap
brew install designsystemmake
```

Or direct formula:
```bash
brew install mrKangHo/DesignSystemMake/designsystemmake
designsystemmake
```

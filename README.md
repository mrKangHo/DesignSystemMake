## 🍺 Homebrew Installation

Install `DesignSystemMake` via Homebrew with 1 command:

```bash
# Tap repository & install DesignSystemMake
brew install mrKangHo/DesignSystemMake/designsystemmake

# Launch DesignSystemMake
designsystemmake
```

## 🌟 Key Features

### 1. 🎨 W3C DTCG Design Token Studio
* **5 Core Token Categories**: Color (Light/Dark dynamic modes), Typography (Font Family, Size, Weight, Line Height), Spacing, Border Radius, and Box Shadows.
* **Built-in Industry Standard Presets**:
  * 🍏 `Apple HIG System`
  * 💨 `Tailwind CSS & Radix UI`
  * 🤖 `Google Material Design 3`
  * 🐜 `Ant Design (B2B)`
* **Custom Presets Manager**: Save your own custom design systems locally (`~/Library/Application Support/DesignSystemMake/custom_presets.json`).
* **WCAG 2.1 Contrast Ratio Evaluator**: Real-time relative luminance calculation ($L = 0.2126 R + 0.7152 G + 0.0722 B$) with AA/AAA pass/fail optical badges.

### 2. ⚡ 100% Complete Multi-Platform Code Exporter
* **📱 SwiftUI (iOS - UIKit & SwiftUI)**: Dynamic `UIColor(dynamicProvider:)` & `Color` extensions.
* **📱 UIKit (iOS Pure Native)**: Standalone `UIColor`, `UIFont`, `UIKitSpacingTokens`, `UIKitRadiusTokens`, `CALayer` shadow extensions without SwiftUI dependencies.
* **💻 SwiftUI (macOS - AppKit & SwiftUI)**: Dynamic `NSColor(dynamicProvider:)` & `Color` extensions for Aqua/DarkAqua.
* **💻 AppKit (macOS Pure Native)**: Standalone `NSColor`, `NSFont`, `AppKitSpacingTokens`, `AppKitRadiusTokens`, `NSShadow`.
* **💨 Tailwind CSS**: Full `tailwind.config.js` theme extension (`colors`, `spacing`, `borderRadius`, `fontFamily`, `fontSize`, `boxShadow`).
* **🎨 CSS Variables**: `:root` and `[data-theme="dark"]` CSS variables.
* **🤖 Jetpack Compose (Android)**: Kotlin `Color`, `TextStyle`, `dp` Spacing, `RoundedCornerShape`, `Shadow`.
* **📱 Flutter (Dart)**: Dart `Color`, `TextStyle`, `BorderRadius`, `BoxShadow`.
* **🌐 W3C JSON (DTCG)**: Official W3C Design Tokens Community Group JSON format.

### 3. ⚡ 1-Click Direct Figma REST API Auto-Sync
* **Figma REST API (`POST /v1/files/{file_key}/variables`)**: Enter your Personal Access Token (PAT) and Figma File URL to push native Figma Variable Collections directly into your Figma project in **0.5 seconds**.
* **Tokens Studio for Figma (JSON)**: 100% compatible JSON export.
* **Figma Variables Plugin JS Script**: Copy-pasteable JavaScript snippet for the Figma desktop developer console (`Cmd+Option+I`).

### 4. 🤖 AI Coding Agent System Context Document Exporter (`.md`)
* Generates structured `DESIGN_SYSTEM.md` context files formatted specifically for **Claude Code, Antigravity CLI, OpenAI Codex, and Cursor**.
* Enforces strict token compliance and prevents AI models from hardcoding raw hex values or arbitrary pixel paddings.

### 5. 🌐 4-Language Internationalization (i18n)
* Supports **Korean (한국어 🇰🇷)**, **English (🇺🇸)**, **Japanese (日本語 🇯🇵)**, and **Chinese (中文 🇨🇳)** with instant toolbar language switching.

## 🛠️ Build & Run Instructions

### Prerequisites
* macOS 14.0 (Sonoma) or later
* Xcode 15.0+ / Swift 5.10 or Swift 6 toolchain

### Build & Execute via Swift Package Manager
```bash
# Clone repository
git clone https://github.com/mrKangHo/DesignSystemMake.git
cd DesignSystemMake

# Build package
swift build -c release

# Launch native macOS app
swift run
```
